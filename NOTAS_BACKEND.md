# \# Backend - Plataforma de Reservas y Ofertas Turísticas

# 

# Este backend será desarrollado con Python, Reflex, Poetry y MySQL Aiven.

# 

# El objetivo del backend es:

# 

# \- Consultar ofertas turísticas relacionadas con el FC Barcelona.

# \- Registrar reservas hechas por usuarios.

# \- Ver el listado de reservas.

# \- Conectarse a una base de datos MySQL alojada en Aiven.

# \- Preparar el proyecto para ser desplegado en Render.

# 

# Ramas del proyecto:

# 

# \- main: versión final estable.

# \- develop: rama general de desarrollo.

# \- backend: trabajo del backend.

# \- frontend: trabajo del frontend.
